# HomeBudget.Domain

Warstwa domenowa aplikacji.

Docelowo tutaj powinny trafić encje, value objecty, enumy i reguły domenowe związane z budżetem domowym, na przykład konta, kategorie, transakcje, budżety, okresy, waluty i reguły cykliczne.

Ten projekt nie powinien zależeć od Blazora, EF Core, ASP.NET Core, klienta HTTP ani konkretnej bazy danych.

Na tym etapie projekt pozostaje pusty od strony klas.

# HomeBudget.Web

Aplikacja webowa Blazor.

Docelowo ten projekt hostuje webowy klient online, rejestruje wspólne komponenty z `HomeBudget.Ui` oraz konfiguruje klienta HTTP z `HomeBudget.Client`.

Web w pierwszej wersji nie działa offline i komunikuje się z danymi wyłącznie przez `HomeBudget.Api`.

Na tym etapie projekt zawiera tylko minimalny szkielet Blazor Web App.

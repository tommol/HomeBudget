# HomeBudget.Client

Wspólny klient HTTP do komunikacji z `HomeBudget.Api`.

Docelowo tutaj powinny trafić typowane klienty API, obsługa tokenów, retry dla bezpiecznych operacji, mapowanie błędów API oraz wspólna konfiguracja `HttpClient`.

Ten projekt ma być używany przez `HomeBudget.Web`, `HomeBudget.Maui` i opcjonalnie testy integracyjne.

Na tym etapie projekt pozostaje pusty od strony klas.

# HomeBudget.Infrastructure.Server

Serwerowa infrastruktura aplikacji.

Docelowo tutaj powinny trafić konfiguracja EF Core, PostgreSQL, migracje, implementacje repozytoriów, integracje OAuth oraz konfiguracja użytkowników i tenantów.

Ten projekt jest używany przez `HomeBudget.Api` i nie powinien być referencjonowany przez klientów webowych ani MAUI.

Na tym etapie projekt pozostaje pusty od strony klas.

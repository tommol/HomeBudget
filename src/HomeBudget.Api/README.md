# HomeBudget.Api

Serwerowe API aplikacji.

Docelowo tutaj powinny trafić endpointy ASP.NET Core dla kont, kategorii, transakcji, budżetów, raportów, profilu użytkownika, odświeżania sesji oraz logowania OAuth.

API jest jedyną warstwą, przez którą klienci mogą uzyskać dostęp do danych biznesowych. Klienci nie łączą się bezpośrednio z PostgreSQL.

Na tym etapie projekt zawiera tylko minimalny szkielet szablonu ASP.NET Core. Endpointy biznesowe nie są jeszcze zaimplementowane.

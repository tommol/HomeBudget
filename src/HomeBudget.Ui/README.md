# HomeBudget.Ui

Wspólna biblioteka komponentów Razor.

Docelowo tutaj powinny trafić współdzielone layouty, strony, komponenty formularzy, komponenty raportów i elementy UI używane zarówno przez `HomeBudget.Web`, jak i `HomeBudget.Maui`.

Ten projekt powinien korzystać z `HomeBudget.Client` i `HomeBudget.Contracts`, ale nie powinien znać EF Core ani PostgreSQL.

Na tym etapie projekt nie zawiera komponentów biznesowych.

# HomeBudget.Maui

Aplikacja .NET MAUI Blazor Hybrid.

Docelowo ten projekt będzie hostem aplikacji instalowanej na Windows, macOS, Android i iOS. Powinien używać komponentów z `HomeBudget.Ui` oraz klienta HTTP z `HomeBudget.Client`.

Projekt może lokalnie przechowywać tylko dane techniczne, takie jak tokeny sesji i ustawienia aplikacji. Dane biznesowe mają pozostać wyłącznie na serwerze.

Na tym etapie projekt zawiera tylko plik `.csproj`. Pełny build wymaga zainstalowanego workloadu MAUI.

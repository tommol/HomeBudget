# HomeBudget.Contracts

Wspólne kontrakty komunikacyjne używane przez API, klienta HTTP, aplikację webową i aplikację MAUI.

Docelowo tutaj powinny trafić DTO, requesty, response'y, modele paginacji, modele błędów API oraz kontrakty raportów.

Ten projekt nie powinien zawierać logiki biznesowej ani zależności od infrastruktury.

Na tym etapie projekt pozostaje pusty od strony klas.
